# AxeOS Fundamentals: Pool Settings, Worker Names, and Failover

A current AxeOS/ESP-Miner fundamentals guide focused specifically on pool configuration rather than firmware architecture or telemetry tuning.

## Core topics
- Stratum URL and port
- Stratum user, payout identity and worker naming
- Pool-specific passwords
- Primary and fallback pool selection
- Stratum V1 and Stratum V2
- V2 channel types, authority keys and authentication
- TLS and certificate verification
- Suggested difficulty
- Extranonce subscription
- Coinbase decoding and share warnings
- Accepted/rejected shares and pool response time
- A safe configuration and verification order
