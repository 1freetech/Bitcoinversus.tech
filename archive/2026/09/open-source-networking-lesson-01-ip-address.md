# Open-Source Networking Lesson #1: What Is an IP Address?

An IP address is an address used to identify a device on a network.

## Think of a Home Address
A package needs an address so it reaches the right home. Networks also use addresses so information reaches the right device.

## Simple IPv4 Example
```text
192.168.1.25
```

For now, just recognize the format. No subnet math or binary conversion is required.

## Familiar Devices
- Phone
- Laptop
- PlayStation or Xbox
- Smart TV
- Bitcoin miner

## Gaming
A game console is a network device. When it goes online, network addressing helps traffic reach the right destination.

## Bitcoin Mining
A Bitcoin miner on a local network has an IP address. Its local management page can commonly be reached using that address.

Remember: **device → IP address → network can find the device.**

## IPv4 and IPv6
IPv4 often looks like `192.168.1.25`. IPv6 addresses look longer. Later lessons will explain the differences.
