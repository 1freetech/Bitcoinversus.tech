# Google’s Intrinsic Open-Sources Core Industrial Robotics Stack

Intrinsic has open-sourced Intrinsic Core, releasing foundational industrial-robotics software under Apache 2.0 so developers can build physical-AI systems on top of ROS-compatible control, perception, simulation and machine-tending tools.

Primary source: https://www.intrinsic.ai/blog/posts/introducing-intrinsic-core
Story X: https://x.com/IntrinsicAI/status/2102401448101433496
Independent source: https://osralliance.org/2026/09/intrinsic-core-the-first-of-a-new-generation-of-ros-distributions/

## A robotics stack built around ROS
Intrinsic Core works with the Open Robotics Suite and includes a local runtime, SDK, digital twin, motion planning, grasp planning, perception and a hardware-agnostic real-time control framework. The software is designed so developers can swap robot arms, grippers and other hardware without rebuilding an entire application stack around each machine.

## The first reference application targets CNC machine tending
Intrinsic is also releasing the Open Machine Tending Solution, a reference design for AI-enabled CNC machine tending.

## Open source could lower the cost of physical AI
Industrial robotics projects often spend significant engineering time integrating controls, simulation, drivers, perception and application logic before a machine performs useful work. By open-sourcing those building blocks, Intrinsic is betting that developers can spend more time on task-specific behavior and less time reconstructing infrastructure that already exists.

The release does not make industrial robotics simple. Intrinsic itself notes that users still need baseline robotics expertise. But putting production-oriented control, digital-twin and perception components into an open stack gives smaller teams access to capabilities that previously required more proprietary integration work.

For physical AI, that may be as important as another robot model. Better shared software can make it easier for the same perception, planning and autonomy ideas to move across different factories and hardware platforms.
