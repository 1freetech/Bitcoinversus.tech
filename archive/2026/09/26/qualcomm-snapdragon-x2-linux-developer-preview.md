Qualcomm is opening its Snapdragon X2 Series laptop platform to Linux developers through an Early Developer Preview focused on upstream, open-source hardware support.

The reference environment uses Debian 13 “Trixie” user space with a custom kernel. Qualcomm says its work is progressing from low-level SoC (System on Chip) enablement toward upstream Linux support for Snapdragon X2 reference hardware.

## Why upstream Linux support matters

Upstreaming gets hardware support into the main Linux projects rather than relying indefinitely on manufacturer-specific patches. Qualcomm says initial enablement includes UEFI (Unified Extensible Firmware Interface) boot support, USB (Universal Serial Bus), PCIe (Peripheral Component Interconnect Express), serial interfaces, power and thermal work, graphics and AI acceleration.

## Open-source graphics and local AI

Qualcomm points to Freedreno, Turnip and Rusticl in the open-source Mesa graphics ecosystem. FastRPC work is intended to provide access to the Hexagon NPU (Neural Processing Unit) for local artificial intelligence inference.

## Ubuntu roadmap

Canonical announced upcoming native Ubuntu support for Snapdragon X2 Series platforms, with certified support targeted for 2027. The current Qualcomm preview remains primarily a developer build-and-test environment rather than a turnkey consumer Linux installer.
