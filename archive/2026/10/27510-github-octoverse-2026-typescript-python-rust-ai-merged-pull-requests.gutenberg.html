GitHub reported October 28 that TypeScript remains its most widely used programming language by monthly contributors, ahead of Python and JavaScript, as AI coding assistants become more prevalent in software development. Its Octoverse 2026 report found detectable AI involvement in 44.1% of merged TypeScript pull requests analyzed over the past year.

Python followed with AI involvement detected in 41.1% of merged pull requests, while Rust registered 40.4%. These numbers do not mean AI wrote that share of code. GitHub measured identifiable agent or AI activity associated with merged requests; detection methods and repository coverage limit what the figures can establish.

TypeScript grows as AI enters code review

Between September 2025 and September 2026, TypeScript added 3.62 million monthly participating contributors, Python added 3.23 million and JavaScript added 1.82 million. Rust had the strongest percentage growth among the report's major languages, up 162%, although its contributor base remains smaller.

GitHub counts distinct accounts participating through pushes, pull requests, issues, reviews or comments, assigning contributions to repositories' primary language. One person can be counted across multiple languages, so the figures are not a census of people exclusively writing TypeScript or Python.

The report also found TypeScript was the primary language in 35% of new repositories with a detectable agent signal, compared with 24% of new repositories without such a signal. That relationship is consistent with agent-friendly development workflows, but it does not prove AI tools caused TypeScript's popularity.

The changes provide context for projects such as a Rust-based TypeScript compiler and GitHub's cross-repository Copilot agents. They suggest developers increasingly combine typed languages, automated code changes and human review.

What the activity figures mean

Across all public and private repositories, GitHub recorded 17.9 billion pushes and 34.3 billion commits in the reporting year ending September 30, 2026. Merged pull requests reached 1.3 billion, although activity totals cannot by themselves establish code quality or productivity.

GitHub forecasts TypeScript and Python could approach 13 million monthly contributors apiece by September 2027. That is a projection, not an achieved milestone. For development teams, the practical challenge remains reviewing, testing and maintaining generated code regardless of which language or agent produced it.
