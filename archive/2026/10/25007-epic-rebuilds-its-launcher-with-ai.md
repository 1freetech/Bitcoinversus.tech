<!-- wp:paragraph -->
<p>Epic Games has released a preview of a completely rebuilt Epic Games Launcher, and the company is making an unusually direct claim about how it was made: Epic says the new client was <strong>“vibe coded” with AI</strong>.</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>In its <a href="https://store.epicgames.com/news/epic-games-launcher-preview">October 14 launch post</a>, Epic says the new launcher was rebuilt from the ground up for speed and responsiveness. The Preview is available on Windows and macOS and, for the first time, as a native Linux application.</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>The headline performance claim is aggressive. Epic’s own benchmark page lists a 5.47-second cold start to the store versus 10.07 seconds for Steam, plus a 0.36-second return from the system tray to the library versus 0.42 seconds for Steam. Epic also says the rebuilt library can load as much as 30 times faster than the previous implementation.</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>Those figures should still be treated as vendor benchmarks, not universal results. Hardware, storage, network state, account state and background services can all change launcher performance. But independent reporting provides some support for the broader speed claim. <a href="https://arstechnica.com/gaming/2026/10/programming-is-hard-epic-games-leans-on-vibe-coding-for-its-new-launcher-app/">Ars Technica</a> reported that its own testing also found the new client reaching the store several seconds faster than Steam.</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>The software architecture may be the more important story. Epic Games Store general manager Martin Keely told PC Gamer that the team started from scratch, using AI as a tool to write and review new features instead of simply analyzing the old launcher. That makes this a real production deployment of AI-assisted software development inside one of gaming’s largest platform companies, not a weekend prototype.</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>The Preview also changes the launcher itself. Users get redesigned library pages, live download and disk-speed information, faster search and filtering, visual collections, customizable navigation, recent-game shortcuts and cross-service party and voice chat. Epic warns that some legacy features are still missing and recommends competitive players continue using the existing launcher during the Preview.</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>Linux support adds another technical layer. Epic is rebuilding Easy Anti-Cheat as EAC Linux v2 and plans to pilot it with Fortnite. The design uses Linux security features such as Secure Boot, signed kernels, measured boot, IOMMU protections, kernel lockdown and eBPF rather than loading a Windows-style anti-cheat kernel driver. If the pilot works, Epic says it intends to make the improved Linux anti-cheat available to other game developers.</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>That combination—AI-assisted development, a native Linux client and a rebuilt anti-cheat stack—makes this bigger than a cosmetic launcher refresh. BitcoinVersus.Tech recently covered <a href="https://bitcoinversus.tech/2026/10/14/epic-free-uefn-verse-bootcamp-ue6/">Epic’s free UEFN and Verse training push</a>, <a href="https://bitcoinversus.tech/2026/10/06/gaming-genex-ai-agents-local-models-visual-checks-game-development/">AI agents entering the game-development loop</a>, and <a href="https://bitcoinversus.tech/2026/10/04/gaming-steam-estimated-1-7-billion-september-2026-revenue/">Steam’s growing PC gaming revenue</a>. The new launcher sits directly at the intersection of those trends: AI-assisted software production, developer tooling and competition for PC players.</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p><strong>Why it matters:</strong> Epic is putting AI-generated code into a consumer gaming platform used at enormous scale and inviting the public to test the result. If the new launcher remains faster and stable as feature parity arrives, “vibe coding” will have moved from a controversial developer phrase into a measurable production case study.</p>
