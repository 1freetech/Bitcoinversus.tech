<!-- wp:paragraph -->
<p>NVIDIA says its new <strong>Nemotron 3.5 Bolt 74B</strong> model will arrive on October 15 for local AI agents running on RTX Spark PCs. In the company’s <a href="https://blogs.nvidia.com/blog/local-ai-rtx-spark-laptops-software-updates/">October 13 software update</a>, NVIDIA describes the model as a 74-billion-parameter mixture-of-experts system with <strong>9 billion active parameters</strong>, compressed into <strong>24GB</strong> using 2-bit quantization.</p>

<!-- wp:paragraph -->
<p>NVIDIA says developers will be able to run the model through llama.cpp, vLLM, Ollama, Unsloth and LM Studio. The company is also moving <strong>PAIR</strong>, its local inference router, out of beta with RTX Spark and llama.cpp support. That fits BitcoinVersus.Tech’s earlier coverage of <a href="https://bitcoinversus.tech/2026/10/07/artificial-intelligence-microsoft-surface-laptop-ultra-rtx-spark-local-ai/">RTX Spark bringing large local models to Windows</a> and <a href="https://bitcoinversus.tech/2026/10/11/microsoft-sandboxes-ai-agents-windows-11/">Microsoft sandboxing AI agents on Windows 11</a>.</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p><a href="https://www.tomsguide.com/computing/laptops/i-have-nvidias-rtx-spark-armed-surface-laptop-ultra-in-my-hands-right-now-tell-me-what-you-want-me-to-test">Tom’s Guide separately confirmed</a> the October 15 model launch and its 24GB target. Independent performance testing is still limited, so NVIDIA’s speed and quality claims should be treated as vendor claims until the model is available.</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>The broader significance is local inference: a model this large running on a personal computer reduces dependence on cloud APIs and keeps more data on-device. For readers building those systems, our <a href="https://bitcoinversus.tech/2026/10/11/what-is-cuda-how-does-it-work/">CUDA explainer</a> covers the software layer underneath NVIDIA’s local AI stack.</p>
