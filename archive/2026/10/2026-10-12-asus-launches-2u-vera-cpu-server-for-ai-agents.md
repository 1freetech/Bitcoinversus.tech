<!-- wp:paragraph -->
<p><strong>ASUS introduced the XA P2N-E2 on October 12, 2026, a 2U NVIDIA MGX server built around two NVIDIA Vera CPUs for agentic AI, reinforcement learning and data-processing workloads.</strong></p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>According to <a href="https://servers.asus.com/news/ASUS-Unveils-XA-P2N-E2-Powered-by-NVIDIA-Vera-CPU-for-Agentic-AI-Workloads-at-OCP-2026">ASUS</a>, the system supports up to two dual-slot NVIDIA RTX PRO 6000 Blackwell Server Edition GPUs, 16 SOCAMM2 memory modules, eight hot-swap E1.S drives, PCIe 6.0 and second-generation NVLink-C2C between the CPUs.</p>
<!-- /wp:paragraph -->

<p>The design targets the execution layer surrounding AI models: code execution, tool use, sandboxing, orchestration and data processing. That fits the broader shift BitcoinVersus.Tech has tracked as <a href="https://bitcoinversus.tech/2026/10/11/ai-agents-7x-more-tokens-openrouter-cache/">AI agents consume more tokens</a>, <a href="https://bitcoinversus.tech/2026/10/12/intel-ai-prompts-right-chip-ocp-2026/">heterogeneous systems route work to different processors</a>, and <a href="https://bitcoinversus.tech/2026/10/12/nvidia-opens-vera-rubin-rack-designs-ocp/">Vera Rubin rack designs move toward open infrastructure</a>.</p>
