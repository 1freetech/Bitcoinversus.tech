<!-- wp:paragraph --><p>Bitcoin block 966,351 was found through Braiins Solo on September 10, ending a 38-day gap between identified solo-pool block finds. The participant received the block's 3.1473 BTC reward under the service's solo payout structure rather than sharing it across a conventional pool.</p><!-- /wp:paragraph -->
<!-- wp:paragraph --><p><a href="https://news.bitcoin.com/mining/solo-bitcoin-miner-hits-244k-jackpot-after-nearly-40-day-drought/">Bitcoin.com documented block 966,351 and the long gap</a>, while <a href="https://mempool.space/block/966351">Mempool's public block explorer provides the on-chain block record</a>. Braiins also <a href="https://twitter.com/Braiins/status/2098011578561892430">confirmed block 966,351 on X</a> and congratulated the participant mining through Braiins Solo.</p><!-- /wp:paragraph -->
<!-- wp:heading --><h2 class="wp-block-heading">One block after weeks of silence</h2><!-- /wp:heading -->
<!-- wp:paragraph --><p>Most miners join pools because Bitcoin block discovery is probabilistic. A pool combines hashrate from many participants and smooths payouts. Solo mining preserves much more variance: long periods can pass between identified blocks, while a successful block pays according to the solo service's terms.</p><!-- /wp:paragraph -->
<!-- wp:paragraph --><p>“Solo” describes the payout arrangement, not necessarily the physical size of the miner. The hardware and hashrate behind block 966,351 were not publicly disclosed, so there is no basis to claim a single home ASIC found it.</p><!-- /wp:paragraph -->

<!-- wp:heading --><h2 class="wp-block-heading">Hashrate buys probability, not a schedule</h2><!-- /wp:heading -->
<!-- wp:paragraph --><p>Every ASIC repeatedly changes block-header inputs and computes SHA-256 hashes. A valid block appears when one hash lands below the network target. More hashrate creates more attempts, but the process does not remember previous attempts or promise when the next valid result will arrive.</p><!-- /wp:paragraph -->
<!-- wp:paragraph --><p>BitcoinVersus.Tech saw the other side of that variance later in September when <a href="https://bitcoinversus.tech/2026/09/27/bitcoin-solo-mining-lands-three-blocks-in-22-hours/">three solo-style blocks landed within roughly 22 hours</a>. A long gap and a tight cluster can both emerge from the same proof-of-work process.</p><!-- /wp:paragraph -->

<!-- wp:heading --><h2 class="wp-block-heading">Why small miners still care about solo mining</h2><!-- /wp:heading -->
<!-- wp:paragraph --><p>The unknown hardware behind this block should not be confused with hobby hardware, but the same probability model is why home-scale devices remain interesting. BitcoinVersus.Tech has covered <a href="https://bitcoinversus.tech/2024/11/25/pierre-rochard-highlights-bitaxe-gamma-for-bitcoin-solo-mining/">Bitaxe Gamma and open-source solo mining</a> as well as the <a href="https://bitcoinversus.tech/2024/12/23/braiins-mini-miner-offers-bitcoin-mining-and-gaming-fun/">Braiins Mini Miner</a>.</p><!-- /wp:paragraph -->
<!-- wp:paragraph --><p>Industrial fleets make vastly more hashing attempts, but every accepted Bitcoin block ultimately comes down to the same test: did one computed hash satisfy the network target?</p><!-- /wp:paragraph -->

<!-- wp:heading --><h2 class="wp-block-heading">The block is permanent proof</h2><!-- /wp:heading -->
<!-- wp:paragraph --><p>The coolest part is that a Bitcoin block leaves a public artifact. Its height, transactions, proof of work, coinbase data and reward can be independently examined after the event.</p><!-- /wp:paragraph -->
<!-- wp:paragraph --><p>Block 966,351 does not make solo mining predictable. It demonstrates the opposite: an unpredictable proof-of-work event can still produce a result that anyone can independently verify.</p><!-- /wp:paragraph -->
