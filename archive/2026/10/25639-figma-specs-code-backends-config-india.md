<!-- wp:paragraph -->
<p>Figma used Config India 2026 on October 15 to push its product farther beyond interface design. The company launched <a href="https://www.figma.com/blog/introducing-figma-specs/">Specs</a>, moved code layers into open beta and added Payload as a native backend path for Figma Make and code-layer projects.</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>Specs stores structured Markdown context beside designs so people and agents can work from the same requirements. Users can bring in code, diagrams and other project material, while code layers let teams build interactive prototypes backed by real code. Payload adds a CMS, database, APIs, authentication and file storage inside the same workflow.</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>The direction matches a point Figma CEO Dylan Field made earlier this year: <a href="https://twitter.com/zoink/status/2043418968929829004">the future is “design AND code.”</a> That matters as <a href="https://bitcoinversus.tech/2026/10/07/coding-google-ai-assistants-live-official-docs-developer-knowledge-api-mcp/">MCP-connected assistants</a>, <a href="https://bitcoinversus.tech/2026/10/07/coding-agent-harness-engineering-vs-loop-engineering-vs-graph-engineering/">coding-agent workflows</a> and <a href="https://bitcoinversus.tech/2026/10/14/ai-developer-rebuilds-word-excel-powerpoint/">AI-built software tools</a> increasingly blur the line between planning, designing and implementation.</p>

TechCrunch also reported that the new tooling is meant to give Figma’s own and third-party agents clearer design rules and production context.</p>
