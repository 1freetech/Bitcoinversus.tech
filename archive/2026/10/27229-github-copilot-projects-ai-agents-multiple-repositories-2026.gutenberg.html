GitHub introduced Copilot Projects in public preview at its Universe conference in San Francisco on October 28, giving developers a way to coordinate AI agents across multiple repositories and tasks from one desktop workspace. The release moves Copilot further beyond code suggestions toward managing entire software-development assignments.

The Copilot app update lets a developer define a goal, supply repositories, design files or meeting notes, and choose appropriate models and tools. Agents can then work in parallel and return results such as proposed pull requests for human review. The project keeps that context, work history and output in one place.

Coordinating agents across repositories

A single feature may require changes to a user interface, a backend service and shared libraries. Copilot Projects is designed to organize those related jobs without requiring the developer to start a disconnected agent conversation for every repository. Users can still run focused sessions directly from an individual repository.

GitHub also introduced project automations for repeatable work. Its wider Universe rollout includes agent-driven review and tools intended to carry work from an initial request through testing and proposed changes. These features make oversight important: suggested code and pull requests still need to be evaluated before they are merged or deployed.

Copilot expands beyond code

The app can draw on connected services including Slack and Figma, helping users work with specifications and designs alongside their code. GitHub also added conversational image generation and editing inside the app, extending the software beyond conventional programming tasks.

A separate computer-use preview launched October 1, allowing Copilot to navigate desktop applications on Windows and macOS, including programs without a suitable API. The tool requests approval before taking control; administrators can disable the feature, and macOS users must grant accessibility and screen-recording permissions.

The launch builds on GitHub’s efforts to scale its infrastructure for AI-generated activity and follows its expanding selection of Copilot models. BitcoinVersus.Tech has also covered Copilot runtime engineering and Microsoft’s safeguards for AI agents.

Copilot Projects is available now as a public preview, but GitHub has not presented it as a guarantee that autonomous changes will be correct. Its practical value will depend on how well agents work across repositories, how clearly their decisions can be reviewed, and whether teams can control spending and access.
