<!-- wp:paragraph -->
<p>Defold 1.14.0 now officially supports <strong>Microsoft Xbox</strong>, giving approved developers another route to ship the same game code across consoles, desktop, mobile and web.</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>The <a href="https://defold.com/2026/10/12/Defold-adds-support-for-Microsoft-Xbox/">Defold Foundation says</a> Xbox support is available free of charge to approved Xbox developers. Teams still need Microsoft approval through programs such as ID@Xbox, then request access to Defold’s Xbox-specific extension, documentation and build workflow. The engine now officially covers Xbox, PlayStation and Nintendo Switch alongside its existing platforms.</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>The coding changes go beyond console access. <a href="https://defold.com/2026/10/12/Defold-1-14-0/">Defold 1.14.0</a> adds cubemap render targets, a redesigned Material Editor, lower editor CPU usage, Metal as the default macOS graphics backend, shader storage buffers for native graphics/compute extensions and support for up to <strong>1,048,576 game objects per collection</strong>.</p>
<!-- /wp:paragraph -->

<p>Defold’s expansion fits a wider push toward more accessible game-development pipelines. BitcoinVersus.Tech has also covered <a href="https://bitcoinversus.tech/2026/10/13/gaming-xbox-labs-emerging-game-technology/">Xbox Labs</a>, <a href="https://bitcoinversus.tech/2026/09/30/gaming-godot-4-8-dev-7-adds-safer-refactoring-and-faster-c-calls/">Godot’s recent engine work</a> and <a href="https://bitcoinversus.tech/2026/10/14/epic-ai-coding-game-development/">Epic’s AI-coding pivot</a>. Defold offers a different angle: a comparatively small, Lua-driven engine trying to make one shared project practical across nearly every major game platform.</p>
