Microsoft on Friday, October 30, extended individual camera, microphone and location permissions for traditional desktop applications to the Windows 11 Insider Experimental (Future Platforms) build 29698.1000. The change lets testers manage access for each participating program instead of relying exclusively on one shared desktop-app permission switch.

The company has tested the feature in other Insider channels before this release. Friday's announcement extends that work to the early-development Future Platforms track, which is not tied to a particular public Windows version. It does not mean the controls are generally available to every Windows 11 PC.

How the desktop app controls work

Users with the feature can open Settings → Privacy & security → Camera, Microphone or Location, review individual desktop applications and allow or deny access separately. The new approach narrows the choice between granting an entire category of desktop programs permission and blocking all of them. Microsoft's standard Windows camera guidance still describes the older shared setting, underscoring the distinction between released software and this preview.

The earlier Experimental 26H1 preview says existing permission decisions are preserved and applications that request a protected resource for the first time may prompt for access. Some applications that use shared components or browser-hosted features may be attributed differently than expected, and unsigned apps warrant extra caution.

For administrators and remote-work teams, narrower permissions could make it easier to approve a videoconferencing client without automatically giving unrelated desktop software the same access. That matters as Windows adds more software-level protections, including sandboxing for AI agents and new recovery features.

What else changes in build 29698.1000

The update also improves multi-monitor taskbar-setting persistence, fixes text in a Recycle Bin deletion message and temporarily rolls back some redesigned loading spinners while Microsoft investigates a bug. The company lists a separate Fortnite matchmaking hang as a known issue.

Microsoft says Future Platforms features can change or disappear before release, with availability phased through controlled testing. The practical next milestone is broader rollout and clearer documentation of which desktop-app integrations and enterprise policies the new controls support. Other recent work on Windows Search and desktop-connected software agents illustrates why explicit app boundaries are drawing attention.
