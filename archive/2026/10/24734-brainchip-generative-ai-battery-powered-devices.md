<p><strong>BrainChip has launched Sequora, a processor IP core designed to run generative AI directly on battery-powered edge devices.</strong> The company said October 14 that the architecture can support models ranging from a few million parameters up to 3 billion while keeping memory use fixed as conversations or data streams grow.</p>
<!-- /wp:paragraph -->

<!-- wp:paragraph -->
<p>According to <a href="https://www.globenewswire.com/news-release/2026/10/14/3380774/0/en/brainchip-launches-sequora-edge-ai-that-doesn-t-just-recognize-it-understands-and-responds.html"><strong>BrainChip’s launch announcement</strong></a>, Sequora uses a state-space design aimed at low-power generative and sequential AI. BrainChip says it can be paired with Akida so one device handles streaming sensor workloads while Sequora runs language, voice and agent-style models.</p>
