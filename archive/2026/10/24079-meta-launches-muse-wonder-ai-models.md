<!-- wp:paragraph -->
<p><a href="https://research.meta.ai/blog/muse-wonder">Meta launched Muse Wonder and Muse Wonder Full on October 12, 2026</a>, calling them its most capable AI models yet. Muse Wonder is available now through the Meta Model API and Muse Code; Muse Wonder Full is limited to Muse Code subscribers. Meta says the models target long-running personal and professional agents, coding, computer use, law, finance and other multi-step work.</p>

<p><strong>Confirmed specs:</strong> Meta’s developer documentation lists a <strong>1,048,576-token context window</strong> for <code>muse-wonder-1.0</code>. Standard API pricing is <strong>$4 per million input tokens</strong>, <strong>$0.20 per million cached-input tokens</strong> and <strong>$20 per million output tokens</strong>. <a href="https://dev.meta.ai/models/muse-wonder">Meta describes Muse Wonder as a preview model</a>; Wonder Full does not currently have public per-token API pricing.</p>

<!-- wp:paragraph -->
<p>The technical theme is persistence. Meta calls its cross-conversation retrieval system <strong>Active Memory</strong> and its long-horizon execution system <strong>Active Focus</strong>. The company says Wonder can recover from errors, try alternate approaches, delegate to sub-agents and ask before consequential actions. Meta also says both models were trained at its gigawatt-scale Prometheus data center.</p>

<p><strong>Claim versus fact:</strong> Meta says the Wonder family reaches state-of-the-art results across several agent, memory and coding evaluations. Those benchmark comparisons are company-reported and should not be treated as independent confirmation. A fuller safety report is also still forthcoming. <a href="https://www.reuters.com/business/media-telecom/meta-releases-muse-wonder-ai-models-challenge-openai-anthropic-2026-10-12/">Reuters</a> separately reported the launch as Meta’s latest push against OpenAI and Anthropic.</p>
