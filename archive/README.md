# BitcoinVersus.tech Story Archive

This directory preserves published BitcoinVersus.tech reporting and research in repository-native files independent of the live WordPress site.

## Archive format

Stories should be stored as Markdown files using:

`YYYY/MM/YYYY-MM-DD-story-slug.md`

Each archived story should preserve, when available:

- title
- original publication date
- canonical BitcoinVersus.tech URL
- category/categories
- author/byline
- article body
- source links
- editor's note and applicable research disclaimers
- referenced media information

## Source

Live publication: https://bitcoinversus.tech/

The archive is intended as a durable historical record. Archived copies should preserve the published text rather than silently rewriting older stories.
