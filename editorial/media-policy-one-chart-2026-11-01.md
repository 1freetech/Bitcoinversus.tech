# BitcoinVersus.Tech visual-media rule — 2026-11-01

**Authority:** Explicit user editorial preference supplied on 2026-11-01. This overrides earlier expectations to use several separate charts in one news article, without changing the featured-cover law, source verification rules, or 2–10 in-story-media quota.

## Mandatory production rule
- Use **no more than one data chart per article or lesson**. When material numeric information warrants a chart, select the single best visualization and explain additional figures in prose.
- Fill the remaining **in-story media slots with relevant material sourced from the internet**: preferably official or Creative Commons-licensed equipment/product/infrastructure photos, authentic screenshots, and tested native YouTube/X embeds. Validate authenticity, attribution, usage rights, the link and dated context. Never invent an embed or call raw URLs working players.
- The user's preferred visual subject is **product and infrastructure hardware**. Use images of people only when editorially necessary. The separate 1200×630 featured cover remains exactly one per story and is not part of the in-story chart count.
- Caption each in-body media item immediately after it, clearly distinguishing historical illustrative photographs from the current event. Put at least one prose paragraph between media items.
- Do not count the featured cover or donation QR as in-story media.
- Prefer 1 chart + 2 or 3 sourced visuals for a quantified story, but never insert unrelated images simply to fill a quota. Correct media problems using Fix → Retest → Replace → Remake.
