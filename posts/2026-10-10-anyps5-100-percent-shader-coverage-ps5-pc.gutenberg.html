The open-source project trying to run PlayStation 5 games natively on Windows and Linux just cleared a big graphics milestone.

AnyPS5 now lists 100% coverage of the 1,166 GPU shader instructions it tracks. That is up from about 96% only a few days ago.

Tom’s Hardware reported the milestone today, while the project’s live progress page tracks shader and system-library work as developers merge changes.

AnyPS5 is not a normal emulator

BitcoinVersus first covered AnyPS5 when the project appeared in September. Instead of recreating an entire PlayStation 5 in software, it relinks PS5 executables into native Windows or Linux programs and replaces console system libraries with open-source implementations.

The shader side matters because the PS5 uses AMD graphics instructions that still need to be translated into something a PC graphics stack can execute. AnyPS5 recompiles those shaders toward SPIR-V for Vulkan.

100% does not mean “PS5 solved”

The important asterisk is huge. The 100% number means every shader instruction on the project’s current tracked list has an implementation. It does not mean every shader behaves perfectly in every game, and it definitely does not mean every PS5 title is playable.

System-library coverage is still incomplete, graphics behavior still needs validation, and individual games can hit missing APIs, synchronization problems, memory issues, or rendering bugs. The project itself warns that its percentages measure implementation progress—not the percentage of PS5 games that work.

The pace is still impressive

The project’s shader tracker moved from 1,118 of 1,166 instructions—about 95.9%—to the full tracked set in only a few days. That kind of pace is one reason AnyPS5 has become one of the more interesting open-source gaming projects to watch this fall.

It also fits a bigger trend BitcoinVersus has been following: modern consumer hardware is increasingly powerful enough to blur the line between consoles and PCs. Sony recently brought QSSR AI upscaling to the standard PS5, while PC developers keep building compatibility layers, emulators, and translation tools around the same AMD-based hardware generation.

SmartNews takeaway

AnyPS5 has now implemented every GPU shader instruction on its current tracking list. That is a real engineering milestone.

It is not the finish line. Think of it as getting every word into the dictionary; developers still have to make sure the whole language works when real games start talking.
